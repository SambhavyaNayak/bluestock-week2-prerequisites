# Bluestock Week 2 Prerequisites

**Objective:** Understand the financial domain and the software ecosystem in which Data Analysts work.

This repository contains all assignments and deliverables completed as part of the Week 2 prerequisites for the Bluestock Data Analyst internship. The tasks cover stock market fundamentals, REST APIs, Git/GitHub, software architecture, and FinTech business understanding.

##  Topics Covered

### 1. Stock Market Fundamentals *(Mandatory)*
Domain knowledge covering NSE & BSE, Nifty & Sensex, IPOs, Market Capitalization, P/E and P/B ratios, EPS, Dividends, Bonus & Stock Splits, Trading Volume, and the three core financial statements (Balance Sheet, P&L, Cash Flow).

> This is intended purely as domain knowledge, not investment or trading advice.

**Deliverables:**
- `01_Stock_Market_Summary.docx` — one-page summary of core stock market concepts.
- `02_Infosys_Financial_Analysis.docx` — financial statement analysis of Infosys Ltd (NSE/BSE: INFY).

### 2. REST APIs & JSON
Covers what an API is, HTTP methods (GET, POST), JSON structure, API documentation, query parameters, and authentication basics, using Postman/Bruno as the testing tool.

**Deliverable:** See [`03-api-data-extraction/`](./03-api-data-extraction) for the full assignment, script, and output.

### 3. Git & GitHub
Covers repositories, clone, commit, push, pull, branches, and pull requests.

**Deliverable:** This repository itself — created, committed, and version-controlled on GitHub.

### 4. Basic Software Development Concepts
Covers Frontend vs Backend, Client–Server architecture, REST APIs, Authentication, Databases, Data Pipelines, Logging, Error Handling, and the SDLC.

**Deliverable:** `04_software_architecture_diagram.jpg` — diagram showing how data flows from a user action in a web application through to a database and finally into an analytics dashboard.

### 5. FinTech Business Understanding
Covers brokerage platforms, Demat accounts, depositories (NSDL & CDSL), SEBI, the trading lifecycle, settlement process, and market participants.

**Deliverable:** `05_FinTech_Research_Report_Groww.docx` — research report on how Groww uses data analytics to improve customer experience and business decisions.
